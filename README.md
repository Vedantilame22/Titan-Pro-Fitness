# 🏋️ Titan Pro Fitness — Modern Gym & Performance Web App

A high-performance, mobile-first web app tailored for independent gym owners, trainers, and fitness members. Designed with a **Deluxe-style persistent background gym radio**, curated workout splits, interactive exercise tutorials, membership renewal reminders, refer & earn, and a real-time admin command center.

🔗 **Live GitHub Repo:** [https://github.com/Vedantilame22/Titan-Pro-Fitness](https://github.com/Vedantilame22/Titan-Pro-Fitness)

---

## ✨ Features Breakdown

### 🌟 Public Showcase
* **Gym Overview & Facility:** Floor stats (12,000 sq ft, 80+ machines, 4.9★ Google rating).
* **Olympic Equipment Gallery:** Filter by Free Weights, Machines, Cardio, and Functional turf with machine quantities and real-time maintenance tags.
* **Membership Plans:** Standard Monthly, Quarterly Beast (most popular), and Annual Champion tiers with savings breakdown.
* **Timings & Working Hours:** 7-day schedule highlighting today's open hours and rush-hour crowd indicators.
* **Special Promo Offers:** Seasonal discount banners with 1-click copy coupon codes.
* **Verified Member Reviews:** Star ratings and member success stories.

### 🎧 Deluxe Ad-Free Workout Radio (Zero Ads)
* Persistent, floating bottom audio player bar that **never stops or restarts** during page navigation.
* Curated ad-free gym streaming stations: *Phonk Energy*, *Electro Pump*, *Heavy Lift Beats*, and *Lo-Fi Recovery*.
* Live animated soundwave frequency equalizer, volume slider, mute, and station switcher.

### 🏋️ Member Companion
* **Renewal Reminders:** Prominent alert countdown badge (e.g. *5 Days Remaining*) with 1-click renewal.
* **Workout Splits:** Tested routines including *Push-Pull-Legs (PPL)* and *3-Day Full Body Power*.
* **Exercise Video & Form Library:** Modal tutorials with YouTube video embeds, target muscle badges, step-by-step cues, and pro form coaching tips.
* **Refer & Earn Program:** Unique member code (`ROHIT20`), one-click link copy with celebration confetti, and WhatsApp share integration.
* **Payment Invoices:** Digital receipt history with payment method and receipt download.
* **Member Voice Drawer:** Submit complaints, equipment requests, and maintenance alerts directly to management.

### ⚙️ Admin Command Center
* **Metrics:** Active members, expiring within 7 days, machinery status, and pending feedback count.
* **1-Click Member Onboarding:** Quickly register new members with custom plans and durations.
* **Renewals Tracker:** Filter expiring members and send instant WhatsApp renewal reminders with one click.
* **Suggestions Inbox:** Review member feedback and mark issues as *Resolved*.
* **Equipment & Offer Controls:** Toggle promo codes and machine availability on/off.

## 🛠️ Free Tech Stack ($0 Cost Architecture)

* **Framework:** React 19 + TypeScript + Vite 6
* **Styling:** Tailwind CSS v4 + Plus Jakarta Sans & Space Grotesk Typography
* **Audio Engine:** HTML5 Audio Context with persistent state
* **Icons:** Lucide React
* **Theme:** Light / Dark mode toggle with zero flicker
* **Deployment Ready:** 100% compatible with Vercel Hobby Tier & Supabase Free Tier

## 🚀 Quick Start Guide

### Prerequisites
* Node.js 18+ (tested on Node v24)
* npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Vedantilame22/Titan-Pro-Fitness.git

# Navigate into the project
cd Titan-Pro-Fitness

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to explore the app!
